## 📌 Project Overview

This project is an interactive **Excel Dashboard** designed to analyze and visualize business performance using sales, revenue, expenses, and profit data.

The dashboard provides a clear overview of key business metrics and helps identify trends across different categories, payment methods, product lines, and regions.

## 🎯 Objectives

- Analyze overall revenue, expenses, and profit.
- Compare performance across different categories.
- Analyze profit based on payment methods.
- Understand revenue generated by different product lines.
- Analyze transaction volume across regions.
- Compare revenue, expenses, and profit trends.

## 📈 Dashboard Insights

The dashboard includes:

- 💰 **Total Profit by Payment Method**
- 📦 **Total Revenue by Product Line**
- 🌍 **Number of Transactions by Region**
- 📊 **Revenue, Expense & Profit by Category**
- 💸 **Average Expense for Each Category**
